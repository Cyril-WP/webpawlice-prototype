WebPawlice

One line on a client's site gives the owner a check-up built from public information: fake email, look-alike domains, certificates, protections, what AI assistants can read, speed, accessibility. Visitors never see it.

See it on a client site Code on GitHub

Put it on a site

Paste before </body>. Nothing runs for visitors.


      

      
    
        
  1. The owner opens their own site with ?webpawlice on the end, e.g. kopiandcrumb.sg/?webpawlice.
    2. 
        
  2. A blue paw appears and runs the check-up. The result is kept for 12 hours in that browser.
    3. 
        
  3. WordPress: paste the line into any "header and footer scripts" setting, or use wordpress/webpawlice.php from the repo.
    4.
